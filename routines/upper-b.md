## Upper B — Tricep/Lat focus

Hevy routine: **Upper B (Tricep/lat focus)**. 2 working sets per exercise unless stated.

| Exercise                           | Working Sets × Reps | Warm-up Sets      | Rest Between Sets | Partial Reps?                                          | Comment                                                                                  |
| ---------------------------------- | ------------------- | ----------------- | ----------------- | ------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| Overhead Triceps Extension (Cable) | 2 × 4–8             | 10 @ 50%          | 90 sec            | Yes* — last set only, bottom-half (stretched position) | Red cables                                                                               |
| Triceps Dip (Weighted)             | 2 × 8–10            | 1 × 8 bodyweight  | 2 min             | No — full depth                                        | Progressed past assisted dips. Hevy routine still lists Triceps Dip (Assisted) — swap it |
| Lat Pulldown (Cable)               | 2 × 4–8             | 8 @ 50% · 5 @ 75% | 2–2.5 min         | No — full stretch to chest                             | Sometimes swapped for Iso-Lateral High Row                                               |
| Chest Press (Machine)              | 2 × 4–8             | 6 @ 60%           | 2.5–3 min         | No — full ROM only                                     | Plate-loaded                                                                             |
| Cable Fly Crossovers               | 2 × 4–8             | —                 | 60–90 sec         | Yes* — last set only, stretched position               | Note which cables (red / middle). Incline DB fly used once as a substitute               |
| T Bar Row                          | 2 × 4–8             | —                 | 2–2.5 min         | No — full stretch to squeeze                           |                                                                                          |
| Lateral Raise (Cable)              | 2 × 8–12            | —                 | 60 sec            | Yes* — last set only, raise to 45°                     | Note which cables (red / middle)                                                         |
| Shoulder Press (Dumbbell)          | 2 × 4–8             | 6 @ 60%           | 2–2.5 min         | No — full lockout                                      |                                                                                          |
| Recline Curl                       | 2 × 4–8             | —                 | 60–90 sec         | Yes* — last set only, bottom-half (stretched position) |                                                                                          |
| Preacher Curl (Barbell)            | 2 × 8–12            | —                 | 60–90 sec         | Yes* — last set only, bottom-half (stretched position) | EZ/straight bar on preacher bench                                                        |

*Partial reps on last set only, after completing the minimum target reps. 3–5 half reps max — no rest-pause between full and partial reps.
