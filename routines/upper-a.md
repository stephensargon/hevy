## Upper A — Chest/Tricep focus

Hevy routine: **Upper A (Chest/Tricep focus)**. 2 working sets per exercise unless stated.

| Exercise                           | Working Sets × Reps | Warm-up Sets      | Rest Between Sets | Partial Reps?                                          | Comment                                              |
| ---------------------------------- | ------------------- | ----------------- | ----------------- | ------------------------------------------------------ | ---------------------------------------------------- |
| Chest Press (Machine)              | 2 × 4–8             | 8 @ 50% · 5 @ 75% | 2.5–3 min         | No — full ROM only                                     | Plate-loaded                                         |
| Overhead Triceps Extension (Cable) | 2 × 4–8             | —                 | 90 sec            | Yes* — last set only, bottom-half (stretched position) | Red cables                                           |
| Triceps Dip                        | 3 × 8               | —                 | 2 min             | No — full depth                                        | Bodyweight. Add weight once 3 × 8 is easy            |
| Cable Fly Crossovers               | 2 × 4–8             | —                 | 60–90 sec         | Yes* — last set only, stretched position               | Note which cables (red / middle) — the stacks differ |
| Iso-Lateral High Row (Machine)     | 2 × 8               | 8 @ 50%           | 2–2.5 min         | No — full stretch                                      | Sometimes swapped for Lat Pulldown                   |
| T Bar Row                          | 2 × 4–8             | —                 | 2–2.5 min         | No — full stretch to squeeze                           | Stop if lower back flares (noted 2 Nov)              |
| Lateral Raise (Cable)              | 2 × 8–12            | —                 | 60 sec            | Yes* — last set only, raise to 45°                     | Note which cables (red / middle)                     |
| Shoulder Press (Dumbbell)          | 2 × 4–8             | 6 @ 60%           | 2–2.5 min         | No — full lockout                                      |                                                      |
| Recline Curl                       | 2 × 4–8             | —                 | 60–90 sec         | Yes* — last set only, bottom-half (stretched position) |                                                      |
| Top Half Reverse Curl              | 2 × 4–8             | —                 | 60–90 sec         | No — already a partial-range movement                  |                                                      |

*Partial reps on last set only, after completing the minimum target reps. 3–5 half reps max — no rest-pause between full and partial reps.
